## Descripcion de esta semana
En esta octava semana realizarás una actividad sumativa individual, en la que completarás el ciclo funcional de tu aplicación integrando la lógica de negocio con la gestión de datos. Para ello utilizarás la programación orientada a objetos junto con la implementación de operaciones CRUD en una base de datos relacional, aplicando técnicas de acceso seguro mediante JDBC.

## Clonar proyecto y ejecutar proyecto

1. Copiar la URL del repositorio de GitHub.
2. Abrir IntelliJ IDEA.
3. Seleccionar File → New → Project from Version Control.
4. Seleccionar Git.
5. Pegar la URL del repositorio.
6. Seleccionar la carpeta donde se guardará el proyecto.
7. Presionar Clone.
8. Abrir Main.java y ejecutar el programa.
